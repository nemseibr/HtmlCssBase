📄 Descrição do Projeto

Este repositório foi criado para exercitar os fundamentos de HTML5 e CSS3, com foco na estruturação semântica de páginas web e na compreensão visual do Box Model.

O projeto apresenta um layout simples e didático, onde cada elemento foi construído com o objetivo de demonstrar, de forma prática, como funciona a organização de uma página utilizando tags semânticas, além de conceitos essenciais de estilização.

🎯 Objetivos de Aprendizado
Compreender o uso de tags semânticas como header, nav, main, article, section, aside e footer
Visualizar na prática o funcionamento do Box Model:
margin (espaçamento externo)
border (borda)
padding (espaçamento interno)
content (conteúdo)
Aplicar conceitos de layout utilizando:
Flexbox (organização de elementos em linha)
CSS Grid (organização em colunas e áreas)
Diferenciar visualmente cada parte da estrutura com uso de cores distintas

🧱 Estrutura do Projeto
O layout é dividido em:

Header → Cabeçalho da página
Nav → Menu de navegação (utilizando Flexbox)
Main → Conteúdo principal (utilizando Grid)
Article → Conteúdo principal da página
Section → Subdivisões do conteúdo
Aside → Conteúdo lateral
Footer → Rodapé

Além disso, há uma área dedicada exclusivamente para demonstrar o funcionamento do Box Model, com cores representando cada camada.

🎨 Estilo Visual
Utilização de cores contrastantes para facilitar a identificação dos elementos
Estilização simples e didática, focada no aprendizado
Layout organizado para facilitar a leitura e entendimento

🚀 Finalidade
Este projeto não tem como objetivo ser um site de produção, mas sim um material de estudo prático
